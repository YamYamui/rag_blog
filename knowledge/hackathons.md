# Hackathons

## NUS Hack&Roll 2026
*Jan 2026 - Feb 2026*

Built a real-time monitoring system for elderly movement patterns using WiFi Channel State Information (CSI)

**Key features:**
- Used [ESPectre](https://github.com/francescopace/espectre) to detect human presence and movement patterns through WiFi CSI data.
- Deployed locally on 4 * ESP32-S3 devices to monitor movement in different rooms, with data aggregated on a Raspberry Pi.
- Developed a web dashboard for real-time visualization of movement patterns and alerts for unusual activity.
![Hack&Roll 2026](assets/6296547216037973296.jpg)

**Tech stack:** React, TypeScript, Tailwind CSS, WebSockets, FastAPI, Python, ESP32-S3, Raspberry Pi

## NUS HealthHack 2025 - Semifinalist
*Jan 2025 - Feb 2025*

Built an AI-driven healthcare assistant prototype focused on realistic patient simulation and medically grounded responses.

**Key features:**

- Simulated diverse patient interactions by deploying Gemini 2.0 Flash for conversations with fictional patients across different medical conditions.
- Integrated Health Hub data via function calling to ground responses in accurate medical terminology.
- Engineered a Retrieval Augmented Generation (RAG) pipeline to retrieve patient backstories from a custom dataset using InterSystems IRIS Vector Search and Vector Store.

**Tech stack:** Python, Gemini API, InterSystems IRIS Vector DB
